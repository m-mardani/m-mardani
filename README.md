# Hi, I'm Mohammad Mardani

**Software Engineer** · Machine Learning · Full-Stack · DevOps

I design and build software end to end: machine-learning systems, full-stack web platforms, mobile apps, and the infrastructure that keeps them running. Most of my recent work is in Python and TypeScript, across recommender systems, multimodal deep learning, data platforms and observability.

## What I work on

- **Machine-learning systems.** Recommender engines (collaborative, content-based and graph neural network models), multimodal emotion recognition and medical audio classification, taken from research notebooks to models that are served and monitored in production.
- **Full-stack platforms.** FastAPI, NestJS and Spring Boot back ends with React and Next.js front ends. Recent projects include project-management dashboards, accounting/ERP software, AI dataset tooling and geospatial analytics, with right-to-left (Persian) interfaces and the Jalali calendar where needed.
- **Infrastructure and DevOps.** Containerised deployments, CI/CD with GitHub Actions, Kubernetes and Helm, and monitoring with Prometheus, VictoriaMetrics, Loki and Grafana.
- **Automation and tooling.** Serverless Telegram bots on Cloudflare Workers, Linux desktop utilities and hardware-support fixes.
